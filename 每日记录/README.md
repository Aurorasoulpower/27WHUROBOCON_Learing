# 每日记录

本目录保存个人日常学习过程，包括当天的工作、试错、现场观察和下次继续的位置，主要供自己回看和接续工作。

## 命名规范

- 文件名使用 `YYYY-MM-DD_主题.md`。
- 一天有多个独立主题时可以分成多个文件。
- 截图和临时数据放入 `assets/YYYY-MM-DD_主题/`。

## 记录原则

- 允许内容不完整，没有明显成果时也可以记录问题、尝试和失败原因。
- 优先写今天改变了什么认识、留下了什么结果、下次从哪里继续。
- 区分实际观察、个人判断和待验证猜测。
- 相同问题不要每天重复抄写，应引用已有专题文档并补充新进展。
- 不在日常记录中承担阶段验收职责，也不要求面面俱到。

## 应写内容

适合记录当天读过的材料、跑过的命令、出现的错误、现场现象、临时结论和下一步动作。
稳定原理放入 `传感器学习/` 或 `ros2学习/`，跨日期成果整理到 `阶段汇报/`，正式方案决策放入 `正赛思路/`。
