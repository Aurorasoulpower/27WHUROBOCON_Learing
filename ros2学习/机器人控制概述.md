# 控制概述

## 一、基本概念
### 1.1 控制回路五要素
- 期望值：目标状态
- 控制器：根据期望与实际计算控制量
- 执行器：电机、舵机、驱动器等
- 被控对象：机器人本体、关节、轮子、机械臂
- 传感器：编码器、IMU、激光雷达、摄像头、力传感器
### 1.2 误差
```text
e(t) = r(t) - y(t)
```
- `r(t)`：期望值
- `y(t)`：实际输出
- `e(t)`：误差

### 1.3 开环与闭环分界
> 控制器输出是否依赖被控对象的实际状态反馈。
- 不依赖：开环控制
- 依赖：闭环控制

## 二、开环控制
### 2.1 定义与结构
按预先设定的命令输出控制量，不测量、不比较、不修正实际结果。
```text
期望值 -> 控制器 -> 执行器 -> 被控对象
```
（反馈通道断开）

### 2.2 优缺点与适用场景
- **优点**：结构简单、实现容易、成本低、响应直接、模型精确且扰动小时有效。
- **缺点**：抗扰动能力差、精度依赖标定和模型、误差会累积、无法自动纠错、环境变化后可靠性下降。
- **适用**：模型准确、环境稳定、低精度要求、扰动小。

## 三、闭环控制
### 3.1 定义与结构
通过传感器获取实际状态，与期望值比较，根据误差调整控制量。
```text
期望值 -> 比较器 -> 控制器 -> 执行器 -> 被控对象
              ↑                         |
              |-------- 传感器 <--------|
```

### 3.2 负反馈
- 实际值低于目标值：增大控制量
- 实际值高于目标值：减小控制量
- 实际值等于目标值：误差为零
- 符号接反会变成正反馈，导致系统发散。

### 3.3 PID
```text
u(t) = Kp * e(t) + Ki * ∫e(t)dt + Kd * de(t)/dt
```
- `Kp`：比例项，误差越大修正越强。
- `Ki`：积分项，消除长期稳态误差。
- `Kd`：微分项，抑制超调和振荡，但会放大噪声。

### 3.4 优缺点与常见问题
- **优点**：能抗扰动、精度更高、自适应更强、可靠性更好、适合复杂任务。
- **缺点**：需要传感器和控制器整定、对实时性要求高。
- **常见问题**：超调、振荡、稳态误差、积分饱和、微分项放大噪声、反馈延迟导致失稳。

## 四、开环与闭环对比
| 维度 | 开环控制 | 闭环控制 |
|---|---|---|
| 是否使用反馈 | 不使用 | 使用 |
| 是否计算误差 | 不计算 | 计算 |
| 抗扰动 | 差 | 强 |
| 精度 | 依赖标定和模型 | 较高 |
| 成本 | 低 | 高 |
| 复杂度 | 低 | 高 |
| 稳定性 | 通常较稳定 | 可能振荡或发散 |
| 传感器需求 | 少或无 | 必须有反馈传感器 |
| 适用场景 | 简单、稳定、低精度 | 复杂、高精度、有扰动 |
| ROS2 典型实现 | 定时器发布指令 | 订阅反馈 + 计算 + 发布指令 |

## 五、机器人为何更常用闭环
**原因**：环境非理想（地面打滑、负载变化、电池电压下降、机械间隙与摩擦、传感器噪声、通信延迟、目标变化）。
**本质**：开环假设“发什么就做什么”，闭环承认“实际不一定做到，需测、比、修”。

## 六、前馈、开环、闭环
- 开环：按预设输出，不看结果。
- 前馈：根据模型提前补偿，但不测输出。
- 闭环：测量输出，根据误差修正。
- 实际系统：前馈 + 反馈 + 滤波 + 限幅 + 安全逻辑。

## 七、ROS2 中的位置
### 7.1 参数 Param
- 放控制器配置项（PID增益、目标速度、控制周期、阈值等）。
- 不是实时控制量。实时控制量走话题。
- 关键代码：
```python
self.declare_parameter('kp', 1.0)
self.kp = self.get_parameter('kp').value
```

### 7.2 通信机制分工
| 通信机制 | 适合内容 | 控制中的角色 |
|---|---|---|
| 话题 | 连续数据流 | 传感器数据、控制指令（如 `cmd_vel`） |
| 服务 | 短请求响应 | 查询状态、切换模式、标定 |
| 参数 | 节点配置 | PID增益、速度上限、阈值 |
| 动作 | 长任务闭环 | 导航、抓取、轨迹跟踪 |

### 7.3 动作 Action 核心字段
- `goal`：目标
- `feedback`：执行过程反馈
- `result`：最终结果
- `cancel`：取消任务
- `status`：任务状态

## 八、工程要点
- **控制频率**：底层电机（几百Hz~几千Hz）、移动底盘（几十Hz）、导航决策（几Hz~几十Hz），要求周期稳定。
- **延迟**：反馈延迟降低稳定性（摄像头、激光雷达、通信、滤波均有延迟）。
- **噪声与滤波**：微分项放大噪声，常用低通、滑动平均、卡尔曼滤波。
- **限幅与抗饱和**：执行器有物理极限，控制量要限幅，积分项抗饱和。
- **QoS**：传感器数据（`qos_profile_sensor_data`）、控制指令（Reliable）、参数（`qos_profile_parameters`）。
- **安全**：看门狗、急停、超时取消、状态监控。
- **生命周期节点**：配置加载参数、激活开始控制、去激活停止输出、清理释放资源。
