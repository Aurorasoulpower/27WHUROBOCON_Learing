# ROS 2 学习

本目录保存 ROS 2 的概念理解、常用命令、代码写法、工具使用和踩坑经验，强调能查、能运行、能迁移到实际机器人项目。

## 命名规范

- 通用主题文档使用 `主题.md`，例如节点、话题、服务、参数和 QoS。
- 有明确日期的实验、课堂记录或问题复盘使用 `YYYY-MM-DD_主题.md`。
- 同一主题的截图和运行输出放入 `assets/主题/`。
- 文件名应使用 ROS 2 中可识别的概念名称，避免过宽泛的标题。

## 记录原则

- 先说明问题和适用场景，再给命令、代码和结果。
- 区分概念解释、可执行示例、个人理解和排错记录。
- 命令应注明执行环境、工作空间和环境变量前提。
- 错误记录应保留原始报错和最终解决依据。
- 上游教程或示例保持原貌，自己的补充单独记录。

## 应写内容

适合记录节点、通信、接口、参数、Action、Launch、QoS、生命周期、工具链、构建系统、调试方法和实际项目中的通信链路。
完整示例代码放入 `d2lros2_code/`，稳定原理和实验结论整理在本目录，阶段成果放入 `阶段汇报/`。
