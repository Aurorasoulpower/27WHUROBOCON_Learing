# 10.4自定义接口 Python 实现

## 一、要做什么

自定义接口，写两个 Python 节点：

- 机器人节点：提供服务 `move_robot`，发布话题 `robot_status`
- 控制节点：调用服务，订阅话题

实现控制节点远程控制机器人移动，同时接收机器人状态。

## 三、要点

### 接口包

- 必须 `ament_cmake` 类型
- 依赖 `rosidl_default_generators`
- `package.xml` 加 `<member_of_group>rosidl_interface_packages</member_of_group>`
- `CMakeLists.txt` 用 `rosidl_generate_interfaces` 注册接口

### 接口文件

- `RobotStatus.msg`：`status` + `pose`（float32）
- `RobotPose.msg`：`status` + `pose`（geometry_msgs/Pose）
- `MoveRobot.srv`：请求 `distance`，响应 `pose`

### 机器人节点

- 服务端 `move_robot`
- 发布者 `robot_status`
- 定时器 0.5 秒发布一次

### 控制节点

- 客户端 `move_robot`
- 订阅者 `robot_status`
- 主函数先 `move_robot(5.0)`，再 `spin`

### 命名一致性

- 服务名、话题名、接口名，两边必须一致
- 常量名以接口文件为准

## 四、踩坑


| 坑                             | 原因                                                                       | 解决                                  |
| ------------------------------ | -------------------------------------------------------------------------- | ------------------------------------- |
| `PackageNotFoundError`         | 没 source 或构建不完整                                                     | 重新编译 +`source install/setup.bash` |
| `self.current_pose` 报错       | 少了下划线                                                                 | 改成`self.current_pose_`              |
| 定时器不执行                   | 函数名`publisher_time_callback` 和注册的 `publisher_timer_callback` 不一致 | 统一                                  |
| `STATUS_MOVING` 报错           | 接口里是`STATUS_MOVEING`                                                   | 两边统一拼写                          |
| 控制节点方法访问不到           | 方法缩进到`__init__` 里了                                                  | 改成和`__init__` 同级                 |
| `self.client_wait_for_service` | 少了`.`                                                                    | 改成`self.client_.wait_for_service`   |
| 请求代码不执行                 | 缩进在`while` 里                                                           | 移到`while` 外                        |
| `entry_points` 放错文件        | 粘到节点文件末尾                                                           | 只放`setup.py`                        |

## 六、当前状态

- 机器人能移动，服务能调用，话题能发布。
- 移动期间控制节点收不到状态话题。
- 原因：单线程执行器，服务回调阻塞了定时器回调。
- 待解决：多线程执行器 + 回调组（进阶篇）。
