# d2lros2_code

本目录保存 ROS 2 教程配套代码、课程练习、工作空间和自行补充的实验代码，主要用于跑通概念并留下可复现的示例。

## 命名规范

- 教程章节和工作空间尽量沿用原教程的目录名称，便于与资料对应。
- 自行增加的笔记使用 `主题.md`，有明确日期的实验使用 `YYYY-MM-DD_主题.md`。
- 自定义接口、节点和功能包使用能表达通信类型和用途的名称。
- 临时工作区、编译产物和导出数据不要用无意义名称长期保留。

## 记录原则

- 上游示例代码和其原始 README 保持原貌，自己的修改和补充另行说明。
- 每个自建示例至少写清运行环境、构建方式、启动命令和预期现象。
- 遇到编译失败、接口不匹配、QoS 不兼容等问题时，记录错误原文和解决依据。
- 代码、原理笔记和阶段汇报分开保存，避免一个文件同时承担多种用途。
- 新增实验应说明它验证了什么，而不只是保存一份可运行的代码。

## 应写内容

适合记录课程示例、节点与通信练习、接口定义、工作空间配置、运行参数、实验现象和自行完成的扩展。
通用概念的系统整理放入 `ros2学习/`，阶段成果和检查证据放入 `阶段汇报/`。
