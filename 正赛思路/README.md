# 正赛思路

本目录保存 ROBOCON 正赛相关的规则解读、任务拆解、系统方案、机构与控制设计、资源分配和风险预案。

## 命名规范

- 一个独立方案使用 `主题方案.md` 或 `主题.md`。
- 需要标明讨论日期的方案可以使用 `YYYY-MM-DD_主题.md`。
- 方案图示放入 `assets/主题/`。
- 名称应体现任务或决策对象，避免只写“方案一”“新思路”。

## 记录原则

- 明确目标、约束和评价指标，不能只记录最终结论。
- 保留当前方案、备选方案、选择依据和被放弃的原因。
- 区分纸面推演、仿真结果、实机验证和比赛现场结论。
- 对未知条件标注待确认，不把假设写成事实。
- 方案变化时补充变更原因和影响范围。

## 应写内容

适合记录规则分析、任务流程、机构与传感器配置、控制策略、场地适应、风险预案、资源需求和关键取舍。
具体原理和实验数据可链接到 `传感器学习/`，阶段完成情况用 `阶段汇报/` 说明。
