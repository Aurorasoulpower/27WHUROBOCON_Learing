# 传感器学习

本目录用于整理相机、激光雷达、IMU 等传感器的原理、标定、数据处理、算法和调试经验，服务于比赛中的实际选型和系统集成。

## 命名规范

- 不依赖日期的原理和方案文档使用 `主题.md`。
- 一次具体实验使用 `YYYY-MM-DD_主题.md`。
- 同一主题的图片和原始输出放入 `assets/主题/`。
- 文件名应体现传感器类型或问题，例如相机标定、AprilTag 位姿或时间同步。

## 记录原则

- 先写问题背景和结论，再写原理、实验步骤和数据。
- 区分理论结论、工程经验和尚未验证的推测。
- 标定参数必须写明设备、分辨率、对焦状态和数据来源。
- 实验需要保留可重复的命令、参考值、误差和异常情况。
- 引用外部资料时说明用途，不直接复制大段教材或源码。

## 应写内容

适合记录传感器工作原理、标定与畸变、坐标变换、滤波、检测识别、时间同步、ROS 2 数据链路、可视化方法和实测结果。
阶段性完成情况和验收证据放入 `阶段汇报/`，日常试错过程放入 `每日记录/`。
