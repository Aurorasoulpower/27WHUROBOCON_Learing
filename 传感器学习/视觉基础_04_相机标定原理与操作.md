## 1. 相机标定在求什么

相机标定利用已知几何尺寸的标定板，估计相机本身的成像参数：

- 内参矩阵 $K$；
- 镜头畸变参数 $D$；
- 标定时的图像尺寸。

它不直接求相机在机器人上的安装位置。相机安装位姿、标签安装位姿和交接机构位姿属于
额外的外参标定。

| 参数 | 描述 | 变化条件 |
| --- | --- | --- |
| 内参 $K$ | 焦距、主点、像素倾斜 | 分辨率、对焦、变焦变化时可能变化 |
| 畸变 $D$ | 径向和切向畸变 | 镜头和成像状态固定时基本不变 |
| 单张图标定外参 | 标定板相对相机 | 每张图不同 |
| 相机安装外参 | 相机相对机器人 | 安装结构变化时变化 |
| 标签安装外参 | 标签相对 TR | 标签位置或方向变化时变化 |

## 2. 为什么 AprilTag 离不开标定

AprilTag 检测只能给出二维像素角点。PnP 必须知道相机怎样把三维点投影成像素：

```text
相机标定：提供 K 和 D
AprilTag：提供图像角点和 ID
标签尺寸：提供真实尺度
        |
        v
PnP：得到标签相对相机位姿
```

如果内参错误，可能出现：

- 中心区域看起来还可以，边缘误差明显；
- 标签左右移动时横向距离有系统偏差；
- 远近变化时深度比例不对；
- 标签倾斜时姿态不稳定；
- 运行重投影误差看似不大，但实际距离不准。

## 3. 张正友平面标定的基本思路

张正友法使用一个平面棋盘，在多个不同姿态下拍摄。

设棋盘平面为世界坐标的 $Z=0$ 平面。理想针孔投影可以化简为：

$$
s
\begin{bmatrix}u\\v\\1\end{bmatrix}
=
K[r_1\ r_2\ t]
\begin{bmatrix}X\\Y\\1\end{bmatrix}
=
H
\begin{bmatrix}X\\Y\\1\end{bmatrix}
$$

其中：

$$
H=K[r_1\ r_2\ t]
$$

$H$ 是每张棋盘图对应的单应矩阵。

旋转矩阵的前两列满足：

$$
r_1^Tr_2=0
$$

$$
\|r_1\|=\|r_2\|=1
$$

由 $H$ 与 $K$ 的关系，每张棋盘图可以提供两条关于内参的约束。多张不同姿态的视图可以
联立求内参初值，然后通过非线性优化同时修正内参、畸变和每张图的外参。

这一步的详细线性推导不是当前操作所必需；实际操作中由
`cv2.calibrateCamera()` 完成。

## 4. 标定为什么需要不同姿态

如果所有棋盘都正对相机并位于画面中央：

- 主点和焦距之间容易相互补偿；
- 边缘畸变几乎没有观测；
- 图像噪声更容易形成错误的最优解；
- 个别异常视图不容易被发现。

较好的采集应覆盖：

- 画面中心和四个边缘区域；
- 不同距离；
- 绕水平和竖直方向的倾斜；
- 绕光轴的小角度旋转；
- 清晰、无遮挡、无明显反光的姿态。

理论上多个视图即可提供约束，实际建议采集 20～30 张质量较好的图。

## 5. 标定误差

标定的基本目标是最小化重投影误差：

$$
\min
\sum_{i,j}
\left\|
m_{ij}
-\pi(K,D,R_i,t_i,M_j)
\right\|^2
$$

其中：

- $i$ 表示第几张棋盘图；
- $j$ 表示棋盘中的第几个内角点；
- $m_{ij}$ 是检测到的像素角点；
- $M_j$ 是已知棋盘三维点；
- $\pi$ 是带畸变的投影函数。

常见指标：

| 指标 | 含义 |
| --- | --- |
| RMS 重投影误差 | 全部样本的总体均方根误差 |
| 单图平均误差 | 每张棋盘图的平均角点误差 |
| 单图最大误差 | 用于发现模糊、反光或角点错误的异常样本 |

没有跨相机通用的固定合格线。应同时比较总体误差、每张图误差和独立验证结果。

## 6. 实际操作前的准备

### 6.1 固定相机状态

- 使用最终运行分辨率；
- 固定 USB 摄像头设备；
- 尽量固定自动对焦、曝光和变焦；
- 标定过程中不要改变分辨率或镜头状态；
- 用稳定设备名确认打开的是目标相机。

自动对焦变化会改变实际光学状态，即使 `K` 文件仍能读取，也可能不再适用。

### 6.2 检查棋盘参数

现有标定脚本默认：

```python
PATTERN_SIZE = (7, 10)
SQUARE_SIZE_MM = 14.3
FRAME_WIDTH = 1280
FRAME_HEIGHT = 720
```

含义：

- 内部角点为 7×10；
- 每个黑白方格边长为 14.3 mm；
- 标定图像为 1280×720。

必须是实际打印后的方格尺寸，不能只照抄程序默认值。

## 7. 采集棋盘图像

代码工作区中的主要程序：

```text
apriltag/test/calib/calibrate_chessboard.py
```

运行前确认：

- `CAMERA_ID` 指向实际摄像头；
- `FRAME_WIDTH`、`FRAME_HEIGHT` 与最终运行一致；
- `PATTERN_SIZE` 与棋盘内部角点数一致；
- `SQUARE_SIZE_MM` 与打印尺寸一致；
- 棋盘平整、没有明显反光。

基本操作：

1. 把棋盘完整放在画面中；
2. 看到角点检测成功后按键保存；
3. 依次改变位置、距离和倾斜角度；
4. 不要连续保存几乎相同的姿态；
5. 检查每帧是否清晰，避免拖影和过曝；
6. 达到建议数量后结束采集。

采集时不要只看“程序说检测到了”，还要看角点是否稳定落在棋盘内部网格交点上。

## 8. 标定参数怎样读

`cv2.calibrateCamera()` 典型输出：

```python
rms, K, dist, rvecs, tvecs = cv2.calibrateCamera(
    object_points,
    image_points,
    image_size,
    None,
    None,
)
```

### 8.1 K

$$
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
$$

像素焦距和主点必须与 `image_size` 配套。

1280×720 的 `K` 不能直接用于 640×360。若相机确实只是等比例缩放，理论上需要同时缩放
`fx、fy、cx、cy`；但不同采集模式可能涉及裁剪或不同视场，实际最稳妥的是同分辨率标定。

### 8.2 dist

五参数形式：

```text
[k1, k2, p1, p2, k3]
```

其中径向和切向畸变的具体解释见
[针孔相机成像原理](视觉基础_01_针孔相机成像原理.md)。

### 8.3 RMS 和单图误差

- 总体 RMS 低，说明整体拟合较好；
- 单图误差突然很大，说明该样本可能有模糊、反光或角点错误；
- 只看总体 RMS，可能让几个异常样本被大量好样本掩盖；
- 标定集误差低也不能替代独立验证。

## 9. NPZ 和 YAML 的衔接

Python 标定脚本常保存 `.npz`，C++ AprilTag 程序通常读取 `.yml`。

一个最小的转换方式：

```python
import cv2
import numpy as np

npz_path = "calibration_chessboard_7x10_14p3mm.npz"
yml_path = "calibration_chessboard_7x10_14p3mm.yml"

data = np.load(npz_path)

fs = cv2.FileStorage(yml_path, cv2.FILE_STORAGE_WRITE)
fs.write("K", np.asarray(data["K"], dtype=np.float64))
fs.write("dist", np.asarray(data["dist"], dtype=np.float64))
fs.write(
    "image_size",
    np.asarray(data["image_size"], dtype=np.int32).reshape(-1, 1),
)
fs.release()
```

转换后手动检查：

- `K` 是 3×3；
- `dist` 是预期的 1×5；
- `image_size` 与实际采集尺寸一致；
- 文件确实被当前 AprilTag 程序读取。

不要只生成新的 NPZ，却继续让 C++ 读取旧 YAML。

## 10. 标定后的验证

### 10.1 分辨率一致

程序中同时打印：

```text
calibration image_size
requested image_size
actual image_size
actual fourcc
```

三者必须符合预期。实际分辨率与标定尺寸不一致时，应停止使用该组内参。

### 10.2 方向验证

固定标签，做容易判断的单轴运动：

- 向右移动；
- 向左移动；
- 远离；
- 靠近；
- 绕竖直轴旋转。

检查横向符号、距离变化和 yaw 方向是否与坐标定义一致。

### 10.3 重复性验证

在同一位置连续采集 30～100 帧，记录：

- 检测率；
- `x/y/z` 均值和标准差；
- `yaw` 均值和标准差；
- 重投影误差；
- 单帧处理耗时。

### 10.4 精度验证

用卷尺或机械定位建立参考值，至少覆盖：

- 中心与画面边缘；
- 近距离与远距离；
- 正对与倾斜；
- 不同照射方向。

区分：

- 随机误差：同一姿态下的上下波动；
- 系统误差：长期偏大、偏小或方向固定偏移。

## 11. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 完全检测不到棋盘 | 内角点数量、棋盘是否完整、对比度 |
| 角点位置不对 | 棋盘反光、模糊、角点顺序 |
| 距离偏大或偏小 | 标签尺寸、分辨率、内参 |
| 画面边缘误差大 | 畸变参数、边缘样本覆盖 |
| 标定前后结果不连续 | 对焦、分辨率、设备节点变化 |
| C++ 仍使用旧参数 | NPZ 是否转成 YAML、YAML 路径 |
| 换了 USB 口后结果异常 | 是否打开了另一台相机 |

## 12. 操作验收清单

- [ ] 相机和最终运行设备一致；
- [ ] 分辨率和最终运行一致；
- [ ] 棋盘内部角点、方格尺寸正确；
- [ ] 样本覆盖画面边缘和不同倾角；
- [ ] 每张样本清晰、无过度反光；
- [ ] RMS 和单图误差已检查；
- [ ] 新参数已写入 YAML；
- [ ] AprilTag 程序确认读取新 YAML；
- [ ] 实际分辨率与标定尺寸一致；
- [ ] 已完成静态重复性和独立精度验证；
- [ ] 记录相机设备、分辨率、对焦状态和验证结果。

## 13. 与 AprilTag 定位的关系

相机标定只完成“相机模型”这一层：

```text
相机标定
  -> K、D、image_size

AprilTag PnP
  -> 标签相对相机位姿

相机安装外参
  -> 相机位姿换到 BR 底盘

标签安装和交接机构外参
  -> 最终交接相对位姿
```

因此，标定 RMS 很好并不代表交接精度已经达标。最终仍需要在实际距离、实际安装和实际
机构位置上验证。
