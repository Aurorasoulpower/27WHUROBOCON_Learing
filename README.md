# ROBOCON 学习与比赛记录

这个仓库用于沉淀学习过程、技术总结和比赛思路。内容以 Markdown 为主，不追求复杂分类，按实际需要逐步补充。

## 目录

- [每日记录](每日记录/README.md)：每天的进展、结论、问题与下一步。
- [传感器学习](传感器学习/README.md)：传感器原理、算法、实验与调试记录。
- [正赛思路](正赛思路/README.md)：比赛策略、机构方案、系统设计和决策记录。
- `d2lros2_code/`：原有 ROS 2 学习代码，作为资料保留，暂不整理。

## 记录约定

1. 文件名以日期或清晰主题开头，例如 `2026-10-24_视觉方案调研.md`。
2. 新记录优先写当前结论，再补充过程，方便以后快速查阅。
3. 涉及方案变更时，写清变更原因、备选方案和待验证事项。
4. 代码、原始数据和图片体积较大时，优先保留在独立位置，文档中只记录索引和结论。
