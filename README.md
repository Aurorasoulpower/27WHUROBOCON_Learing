# ROBOCON 学习与比赛记录

本仓库用于保存 27 届 ROBOCON 备赛过程中的学习笔记、调试记录、阶段进度和技术方案。

## 内容划分

仓库按文档用途分为日常过程、阶段汇报、专题学习、比赛方案和 ROS 2 学习资料。
日常过程允许零散和试错；阶段汇报用于集中说明一段时间内的完成情况；专题学习保存可复用的原理和方法；比赛方案保存经过讨论和验证的设计决策。

## 命名规范

- 单日记录使用 `YYYY-MM-DD_主题.md`。
- 跨日期阶段使用 `YYYY-MM-DD_YYYY-MM-DD_主题.md`。
- 不依赖具体日期的专题文档使用清晰的 `主题.md`。
- 图片、截图和日志等附属材料放入对应目录的 `assets/主题/` 中。
- 文件名应直接说明内容，避免“其他”“杂项”“新建文档”等无意义名称。

## 记录原则

- 先写结论和当前状态，再补充过程与依据。
- 明确区分已完成、已验证、待验证、未开始和阻塞。
- 重要结论应能对应到命令、输出、截图、代码或其他可检查的证据。
- 失败尝试和方案变更也要记录原因，避免以后重复踩坑。
- 大体积代码、原始数据和二进制文件不复制进文档，保留在独立位置。
- 记录应让未参与当天工作的人能够理解背景并找到继续工作的位置。

## 写作边界

这里记录自己的理解和实践，不复制完整教材，也不修改上游示例的原始说明。
原理性内容应结合本队使用场景；比赛方案应说明依据和风险；日常记录不承担阶段验收职责。
